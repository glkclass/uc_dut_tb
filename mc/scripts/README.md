# Scripts to create / run Vitis project


### Usage:

- Task 1: Create Vitis workspace & project (Debug config) from scratch using py scripts. The workspace will be created in `<mc_root_folder>/vitis_ws` folder.
```
	cd <mc_root_folder>/scripts
	make create_debug_project
```

- Task 1: Create Vitis workspace & project (Release config) from scratch using py scripts. The workspace will be created in `<mc_root_folder>/vitis_ws` folder.
```
	cd <mc_root_folder>/scripts
	make create_release_project
```

- Task n: See `<mc_root_folder>/scripts/makefile` for more usage cases..
